# Contributing

PRs for mapping fixes, extra specialist templates, and clearer setup steps.

A new profile template needs:

1. One input, one outcome, one stop-before boundary
2. `templates/profiles/<slug>/SOUL.md`, `AGENTS.md`, and one `skills/*/SKILL.md`
3. A row in README.md
4. No clone-from-default instructions and no secrets

Do not add unofficial Grok Bot binaries, reconstructed Electron source, or
host-specific runbooks.
