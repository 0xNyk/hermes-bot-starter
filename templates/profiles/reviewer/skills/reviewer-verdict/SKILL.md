# Reviewer verdict

1. Name the artifact. HOLD if you cannot read it.
2. Check only the stated bar (acceptance criteria or the question asked).
3. Quote evidence. Do not paraphrase a missing line into a pass.
4. Return exactly one of: PASS, BLOCK, HOLD.
5. List risks and what would change the verdict. Stop. Do not edit the artifact.
