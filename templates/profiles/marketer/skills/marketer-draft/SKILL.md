# Marketer draft

1. Name audience, offer, and channel.
2. Write the draft. Stay inside the channel limit if one was given.
3. Risk note: claims that need a source, spend, or legal review.
4. Do not invent a public URL. If the repo remote is unknown, say so.
5. Stop. Do not post.
