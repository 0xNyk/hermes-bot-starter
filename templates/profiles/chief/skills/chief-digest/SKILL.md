# Chief digest

1. Confirm the time window and the priority filter. If none given, ask once.
2. Read only the sources named or already in this chat. Do not spray-search.
3. Drop items that do not map to a priority.
4. For each kept item: source, why it matters, next step, whether a human decision is owed.
5. Stop. Do not create a routine. Do not @mention another bot unless the user named the destination and the request.
