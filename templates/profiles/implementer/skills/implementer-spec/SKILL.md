# Implementer spec

1. Confirm the spec version or issue id. Stop if none.
2. Implement only listed acceptance criteria. No drive-by cleanup.
3. Add or run the verification the spec names. If none, say so.
4. Summarize what changed and what you did not touch.
5. Stop for human review. Do not merge, deploy, or ask reviewer yourself unless the user named that handover.
