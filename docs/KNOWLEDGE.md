# What each Bot ships

Each specialist template is four pieces:

| File | Job |
|---|---|
| `SOUL.md` | Durable identity and stop-before |
| `AGENTS.md` | Short operating rules loaded every session |
| `skills/<name>/SKILL.md` | How to do the one standing task |
| profile `ui_meta` | Title, rooms (not in git) |

Do not clone `default`. Do not copy bundled marketing skills into these
profiles. One skill per Bot is the point.
